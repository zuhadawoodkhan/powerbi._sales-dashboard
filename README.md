## Project Overview

An interactive Power BI sales dashboard designed to analyze sales performance, trends, customer/product performance, and geographic insights.

The project focuses on transforming sales data into an interactive reporting solution that can support business analysis and decision-making.

## Tools & Technologies

* Microsoft Power BI
* Power Query
* Data Cleaning & Transformation
* Data Visualization
* DAX
* Interactive Slicers
* KPI Reporting

## Dashboard Pages

### Page 1 — Sales Overview

The first dashboard page provides an overview of sales performance using multiple visualizations and KPIs.

Key visualizations include:

* Sales KPI cards
* Sales trend analysis
* Category/product analysis
* Percentage-based comparisons
* Customer/product performance
* Scatter analysis
* Interactive filtering

### Page 2 — Sales Analysis

The second page provides additional analysis through:

* Interactive slicers
* Gauge/KPI analysis
* Geographic analysis using Azure Maps
* Sales and trend comparison
* Waterfall analysis

## Key Analysis Areas

The dashboard can be used to explore:

* Overall sales performance
* Sales trends over time
* Product/category performance
* Geographic sales distribution
* Performance comparisons
* Changes contributing to overall sales results

## Data Preparation

The dataset was prepared for analysis by applying data transformation and cleaning steps before building the dashboard.

The Power BI model was then used to create calculated metrics and interactive visualizations.
